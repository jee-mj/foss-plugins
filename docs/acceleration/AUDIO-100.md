## Products and distinct requirements

- `ear-trainer` — application/test-signal/lesson logic, [trainer processor](https://github.com/bogggare567/abcTrain/blob/09f21857cd23bf50c5285f6f19ab221cb1c23777/Source/PluginProcessor.cpp); ordinary DSP exercises and optional Studio dispatch to Learner processors.
- `learner-eq` — [processor](https://github.com/bogggare567/abcTrain/blob/09f21857cd23bf50c5285f6f19ab221cb1c23777/LearnerEQ/Source/PluginProcessor.cpp): coefficient glide, filter stages and analyzers, no inference.
- `learner-comp` — [processor](https://github.com/bogggare567/abcTrain/blob/09f21857cd23bf50c5285f6f19ab221cb1c23777/LearnerComp/Source/PluginProcessor.cpp): detector, optional external/self/kick key, gain computation and wet/dry blending, no inference.
- `learner-verb` — [processor](https://github.com/bogggare567/abcTrain/blob/09f21857cd23bf50c5285f6f19ab221cb1c23777/LearnerVerb/Source/PluginProcessor.cpp): conventional reverb engine and mixing, no inference.
- `bot-listener` — **small local learned inference**, not neural audio processing. [BotListener::chanceOfRight](https://github.com/bogggare567/abcTrain/blob/09f21857cd23bf50c5285f6f19ab221cb1c23777/Source/BotListener.cpp#L78-L95) evaluates a one-unit logistic perceptron using compiled threshold/slope/lapse weights and samples an answer. [BotWeights.h](https://github.com/bogggare567/abcTrain/blob/09f21857cd23bf50c5285f6f19ab221cb1c23777/Source/BotWeights.h) embeds six bots' weights. [PerceptualModel](https://github.com/bogggare567/abcTrain/blob/09f21857cd23bf50c5285f6f19ab221cb1c23777/Source/PerceptualModel.cpp) calls it from opponent-answer logic. The class name “RuleBased” does not erase use of learned logistic weights. No model-file loader or ORT/PyTorch is needed.
- `bot-training` — [train_bots.py](https://github.com/bogggare567/abcTrain/blob/09f21857cd23bf50c5285f6f19ab221cb1c23777/tools/bots/train_bots.py) uses NumPy and manually implemented Adam maximum-likelihood fitting. Training data are simulated literature-derived teacher answers with explicitly invented game choices; optional real-answer CSV input exists. This is a CPU offline training tool, not GPU training or an audio model.

[CMake](https://github.com/bogggare567/abcTrain/blob/09f21857cd23bf50c5285f6f19ab221cb1c23777/CMakeLists.txt) separates trainer engine, shared conventional DSP, and the three Learner processor libraries.
